# 类别方案要点

## 土建改造

- 先识别病害机理和边界，再确定拆除、基层处理、节点修复、防水或结构修复、面层恢复和养护顺序。
- 材料原则强调与基层及使用环境相容、耐久、可维护和节点连续，不在事实不足时指定品牌型号。
- 常见计量对象包括处理面积、裂缝或接缝长度、节点数量、拆除与恢复面积、保护面积、检测点或试验项。
- 验收结合过程影像、隐蔽验收、观感、尺寸或厚度、闭水/淋水/功能验证及缺陷复查。

## 机电改造

- 先核对容量、接口、控制和运行保障，再确定隔离切换、拆除、基础支吊架、设备或部件安装、管线电缆接入、调试联动和试运行顺序。
- 材料原则强调既有接口兼容、容量匹配、安全等级、环境适用性、维护空间和备件可得性。
- 常见计量对象包括设备台数、管线或电缆长度、阀门与控制点数量、基础及支吊架数量、保温恢复面积、调试系统或检测项。
- 验收结合单机参数、联动逻辑、保护功能、连续运行、噪声振动、能耗或设计工况验证。

## 工程量骨架

每个成本项至少包含：名称、规格待确认内容、建议单位、计量依据、关联方案模块。把“现场复核尺寸”“按点位清单统计”“按系统图或回路核对”等写成申报人可执行的测量任务。
