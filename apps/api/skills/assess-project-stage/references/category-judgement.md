# 类别判断要点

## 土建改造

- 必要性：识别渗漏、开裂、空鼓、沉降、锈蚀、功能损坏等问题是否持续、扩大或影响安全与使用；区分局部维修、周期性维护和需要系统改造的情形。
- 可行性：关注病害机理是否基本明确、基层和隐蔽条件、排水或结构边界、占用区施工、养护时间、成品保护及闭水或功能验证条件。
- 立项阶段不要求完整施工图，但应明确范围、对象、主要做法方向和后续深化责任。

## 机电改造

- 必要性：关注故障频率、能效、容量、可靠性、备件和维修替代路径；单次故障且可稳定修复时不宜直接支持整体更换。
- 可行性：关注既有系统接口、容量、电源与控制逻辑、停机切换、临时保障、调试联动、维保空间及验收运行周期。
- 不能只凭设备年限判断更换，应结合故障、性能、维修可得性和运行影响。

## 共同判断

- 证据证明问题存在，不代表方案天然正确。
- 风险存在不等于不可行；应判断控制措施和施工窗口是否足以降低风险。
- 对关键未知要求补充，对非关键未知可作为显式假设进入后续方案。
- 证据只覆盖部分对象时，先判断该部分能否形成独立、可验收的工程边界；可以独立实施则提出范围校准，不得机械要求补齐原范围全部对象。
