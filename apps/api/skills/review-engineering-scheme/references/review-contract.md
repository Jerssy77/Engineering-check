# 复核缺陷分类

- `vague_route`: 技术路线仅有目标或流程，没有工程机理。
- `critical_parameter_deferred`: 影响路线、选型或安全的参数被留待深化。
- `unsupported_assumption`: 关键现场条件无事实支持。
- `interface_gap`: 既有系统、基层、结构、电源或控制接口未闭合。
- `quantity_untraceable`: 工程量无法追溯到具体方案动作。
- `acceptance_unverifiable`: 验收无法测量或记录。
- `false_alternative`: 备选没有实质技术差异或适用条件。

存在前六类任一缺陷时不得通过。警告只用于不改变路线的表达或维护性问题。
